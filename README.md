# ORBIT — 3D Animated Landing Page

A cinematic, responsive landing page built with React, Vite, Three.js, and Lucide icons. Features a live 3D animated orb, interactive pointer response, orbit rings, starfield, gradient typography, reveal-on-scroll sections, and mobile navigation.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

Import this repository into Vercel or Netlify and use `npm run build` as the build command and `dist` as the output directory. Alternatively, configure GitHub Pages with a Vite deployment workflow.

## Customize

- Update the brand and copy in `src/main.jsx`.
- Adjust the 3D material, lighting, geometry, and motion in `OrbScene` in `src/main.jsx`.
- Change colors, spacing, responsiveness, and animations in `src/style.css`.

The current design uses the fictional studio brand **ORBIT** as a polished starting point; replace the name, email, and copy with your own details before launch.
